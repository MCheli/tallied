Written after getting the app running locally for the first time in months and reading across the whole codebase (backend, frontend, integrations, AI features, docs), plus a Playwright screenshot pass of every page at 390px and 1440px. No features were added. Items have stable ids so decisions can refer to them.

Severity: **H** fix soon, **M** should fix, **L** nice to have. Effort: **S** under half a day, **M** a day or two, **L** several days.

## What happened today

- Docker is not installed on the Mac mini, so Postgres 16 now runs as a Homebrew service (`brew services start postgresql@16`). Role `tallied`/`tallied_dev`, database `tallied`. `make db-start` will not work on this machine.
- SQLAlchemy 2.1 (released after the last commit) switched the default `postgresql://` driver to psycopg 3, which broke every test and the app. `requirements.txt` is now pinned to `sqlalchemy>=2.0.0,<2.1` because `sync_scheduler.py` imports psycopg2 directly.
- `alembic upgrade head` fails on an empty database (BUG-1). Local setup used `scripts/seed_test_data.py --reset` followed by `alembic stamp head`.
- The Planning page returned 500 for the seeded plan: `AssumptionResponse.description` was typed `str` while the model allows null. Fixed in `backend/app/schemas/planning.py`.
- The seed called the projection engine with the wrong arguments, so the seeded plan had no projections. The seed now goes through `planning_service.create_plan` and reports 58 projection rows.
- Backend tests: 41 pass. Frontend `vue-tsc`: clean. Both dev servers run; login as Claudius works.

Uncommitted: `backend/requirements.txt`, `backend/app/schemas/planning.py`, `scripts/seed_test_data.py`.

## G. Specs and process

Every file in `docs/` dates from 2026-03-22; the code has 31 commits since. Three docs are contradicted by the code: `PLATFORM_VISION.md` says webhooks, rate limiting and direct DB access are "not started" (all shipped in the same commit); `IMPORT_WORKFLOW.md` says "not yet implemented" (it is, with 45 tests); `SECURITY_AUDIT.md` marks four findings remediated while the commit says all critical/high/medium were. CLAUDE.md says "a requirement is done only with evidence; update the ledger in the same commit."
